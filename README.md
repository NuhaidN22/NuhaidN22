## Featured projects

### 🛰️ [cloud-monitoring-agent](https://github.com/NuhaidN22/cloud-monitoring-agent)
Low-overhead observability agent that collects kernel/hardware metrics in **C**, bridges them into **Go** via Cgo, and exposes concurrent REST APIs. Storage provisioned with **Pulumi**, shipped as a multi-stage **Docker** image.
`Go` `C` `Cgo` `AWS S3` `Pulumi` `Docker`

### 🛡️ [IntelliShield](https://github.com/NuhaidN22/IntelliShield)
Network intrusion detection system: a **Go** packet-capture pipeline feeding a Python ML ensemble (XGBoost, Random Forest, Isolation Forest, LSTM, DBSCAN), with alerts stored in **Elasticsearch** and visualised in **Kibana**. Dockerised with CI via GitHub Actions.
`Go` `Python` `TensorFlow` `Elasticsearch` `Kibana` `Docker`

### 🔌 [API-Crud](https://github.com/NuhaidN22/API-Crud)
Go REST API with CRUD endpoints.
`Go` `REST`
